### Rule 8: Parent vs. Subordinate Imbalance Hierarchy
- **RULE:** A higher-timeframe (parent) Fair Value Gap takes precedence over smaller-timeframe (subordinate) Fair Value Gaps; an intraday setup only becomes valid after price trades into the parent higher-timeframe imbalance.
- **CATEGORY:** reference level / confirmation
- **NUMBERS:** 15m parent FVG governs 5m/lower FVG entries.

### Rule 9: Order Block Validity Requirement (Imbalance Condition)
- **RULE:** A series of up-close candles is only classified as a valid Bearish Order Block if the subsequent downward price displacement creates an imbalance (Fair Value Gap); without a displacement-induced imbalance, the candles are not an order block.
- **CATEGORY:** reference level / confirmation

### Rule 10: Multi-Candle Bearish Order Block Definition
- **RULE:** When multiple consecutive up-close candles precede a downward displacement with an imbalance, the entire consecutive run of up-close candles forms the Bearish Order Block, and its activation level begins at the lowest open/low of the first candle in that consecutive run (not just the final candle).
- **CATEGORY:** reference level / entry
- **NUMBERS:** 3 consecutive up-close candles shown in example.
- **SOURCE:** 38:16–38:32, 42:28–43:10 (Said and Showed).

### Rule 11: Low-Threshold Limit Entry at First Imbalance Threshold
- **RULE:** To avoid missing trades when multiple Fair Value Gaps form during displacement, place a sell limit order at the low/discount threshold of the first (lowest) subordinate Fair Value Gap (or +1 pip above it for spread), rather than holding out for higher secondary gaps.
- **CATEGORY:** entry
- **NUMBERS:** +1 pip offset for spread.

### Rule 12: Stop-Loss Placement Above Displacement Imbalance High

## Conditions that Cancel a Setup / Filters (What NOT to do)

1. **No Mobile Phone Order Placement:** Do not execute new trade entries on a smartphone. Analysis and entry require the screen real estate of a desktop/laptop monitor to evaluate the structure and context.
2. **11:30 AM Cutoff Rule:** If a pending limit order is not filled by 11:30 AM New York local time, cancel it immediately. Do not keep orders working into late lunch/afternoon sessions.
3. **No Displacement = No Order Block:** Do not treat up-candles preceding a price decline as an order block if the decline fails to create an imbalance (Fair Value Gap).
4. **Do Not Trade Counter to Higher Timeframe Imbalance:** Do not look for lower-timeframe short setups until price has traded up into the parent higher-timeframe premium imbalance (FVG/liquidity pool).
5. **No Single-Day Greed Targets:** Do not target major multi-week or multi-month swing lows on an intraday timeframe when framing a day trade; use the previous day's high/low.

## Gold (XAUUSD) vs. Forex Pairs vs. Indices Differences

- **Forex (EUR/USD):**
  - Uses the 07:00 AM to 10:00 AM New York local time killzone for trade setup and entry.
  - Daily order flow and prior daily highs/lows govern the primary liquidity targets.
- **Index Futures:**
  - Michael explicitly notes that when trading Index Futures, certain specific caveats and rules differ from Forex (points vs. pips, differing session nuances), which he separates from this pure Forex lesson (08:26–08:35).
- **Gold (XAUUSD):**
  - Gold is described as an "event-driven market" heavily impacted by geopolitical news and shocks (51:41–52:20).
  - Gold is subject to extreme stop hunts, erratic manipulation, and choppy consolidations, making it sub-optimal and frustrating for disciplined, short-term algorithmic model execution compared to Forex.

## Ambiguities and Open Questions

1. **Exact Pip Offset for Entry:** Michael mentions adding "+1 pip" to the limit order for spread coverage when shorting an FVG, but brokers have varying variable spreads on EUR/USD. The exact buffer required for an automated engine needs to be dynamically tied to the broker's real-time spread.
2. **Dual Stop-Loss Options:** Michael offers two options for stop placement:
   - Conservative: Above the swing high that swept liquidity.
   - Aggressive: Above the high of the individual candle that initiated the displacement imbalance.
   An automated algorithm must define a deterministic boolean rule (e.g., based on R:R or maximum pip threshold) to decide between the two.
3. **Multi-Candle Order Block Open Level:** When defining a multi-candle consecutive order block, Michael refers to the lowest candle body/low of the run as the threshold where delivery shifted, rather than traditional single-candle definitions. Precise code specifications must determine whether to anchor to the lowest candle's *open* or *low*.
